>
> **Фрагмент из [`readme.md`](https://github.com/bol-van/zapret-win-bundle/blob/master/readme.md#%D0%B0%D0%BD%D1%82%D0%B8%D0%B2%D0%B8%D1%80%D1%83%D1%81%D1%8B) репозитория [bol-van/zapret-win-bundle](https://github.com/bol-van/zapret-win-bundle)*
>
> Некоторые антивирусные программы классифицируют файлы WinDivert как инструменты повышенного риска или хакерские утилиты, после чего удаляют их либо отправляют в карантин. Такой детект обязательно содержит название `WinDivert` или `Not-a-virus:RiskTool.Multi.WinDivert`
>
> Добавьте каталог с zapret в исключения антивируса или выключите обнаружение PUA — потенциально нежелательных приложений. Например, в Kaspersky для этого предусмотрен пункт "Обнаруживать легальные приложения, которые злоумышленники часто используют для нанесения вреда". Если вы умеете аккуратно настраивать исключения, лучше добавить исключение; если не уверены в своих действиях, рекомендуется отключить детектирование PUA.

## ⚙️Использование

1. Активируйте Безопасный DNS (Secure DNS)
    * В Chrome включите "Использовать безопасный DNS" и укажите поставщика DNS, отличного от варианта "Поставщик по умолчанию"
    * В Firefox откройте "DNS через HTTPS", установите режим "Персональный", затем нажмите "Выбрать провайдера/поставщика" и вручную задайте URL. Например: `https://dns.google/dns-query`, поскольку Cloudflare может быть заблокирован
    * Windows 11 позволяет активировать Secure DNS непосредственно в параметрах системы — [инструкция здесь](https://remontka.pro/dns-over-https-windows-11/). Этот способ рекомендуется пользователям Windows 11
    * Владельцам роутеров Keenetic нужно включить параметр "Транзит запросов". Если он отключён, на компьютере могут возникнуть сложности с настройкой и использованием Secure DNS

2. Загрузите архив (zip/rar) на [странице актуального релиза](https://github.com/ExistenceAuditor/zapret-discord-youtube/releases/latest)

3. Откройте свойства загруженного архива и отметьте "Разблокировать". При использовании 7-Zip или PeaZip этот пункт выполнять не требуется

4. Извлеките файлы в каталог, путь к которому не включает кириллицу и специальные символы

5. Откройте необходимый файл
    * Чтобы определить рабочую стратегию: **`service.bat`** -> `Run Tests` -> `Standard tests` -> `All configs`
    * Чтобы добавить её в автозапуск: **`service.bat`** -> `Install Service` -> *выберите подходящую стратегию*

## ℹ️Что делают файлы

- [**`general.bat ...`**](./general.bat) — ручной запуск стратегии

  Ручной режим удобен для проверки стратегий. Результат каждой из них зависит от множества условий. **Перебирайте разные варианты, включая ALT и FAKE, пока не найдёте подходящее для себя решение**

- [**`service.bat`**](./service.bat) — автозапуск и дополнительные возможности:
  - <ins>**`Install Service`** — добавление выбранной стратегии в автозапуск (services.msc)</ins>
  - **`Remove Services`** — удаление стратегии и WinDivert из списка служб
  - **`Check Status`** — просмотр состояния обхода и служб: стратегии в автозапуске и WinDivert
  - **`Game Filter`** — смена режима обхода для игр и других сервисов, работающих по UDP и TCP на портах выше 1023.  
  **После изменения режима стратегию необходимо перезапустить.**  
  Текущее состояние — включено или выключено — отображается в скобках.
  - **`IPSet Filter`** — выбор режима обхода сервисов, перечисленных в `ipset-all.txt`.  
  Эта функция полезна при тестировании ресурса, который доступен без zapret, но не работает вместе с ним  
  В скобках показывается активный режим:
    - `none` — IP-адреса не проверяются
    - `loaded` — проверяется наличие IP-адреса в списке
    - `any` — фильтрация применяется к любому IP-адресу  
  - **`Auto-Update Check`** — включение или отключение автоматического поиска обновлений
  - **`Replace active fakes`** — замена указанного активного фейка другим файлом из каталога `bin`
  - **`Update IPSet List`** — загрузка актуального списка `ipset-all.txt` из репозитория
  - **`Update Hosts File`** — обновление hosts <ins>**для восстановления веб-версии Telegram и соединения с голосовым чатом Discord**</ins>
  - **`Check for Updates`** — поиск доступных обновлений
  - **`Run Diagnostics`** — поиск распространённых проблем, из-за которых zapret может не запускаться или не работать.  
  В завершение можно удалить кэш <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=11 /> `Discord`: это иногда помогает, когда приложение внезапно перестаёт подключаться
  - **`Run Tests`** — открытие инструмента проверки работоспособности стратегий:
    - `Standard tests` — тестирование сайтов, указанных в `utils/targets.txt`
    - `DPI checkers` — диагностика DPI через разных провайдеров, включая Cloudflare, Amazon и другие


## ☑️Частые вопросы и неполадки

### При открытии скрипта `general*` ничего не происходит

- Если стратегия запускается отдельным bat-файлом, а не через service, должен появиться winws.exe — процесс обхода, отображаемый на панели задач.  
Если его нет, ознакомьтесь с [#522](https://github.com/ExistenceAuditor/zapret-discord-youtube/issues/522)

### Не удаётся подобрать рабочую стратегию
- Откройте командную строку с правами администратора
- По очереди выполните в консоли следующие команды:

    `netsh winsock reset`
  
    `netsh int ip reset all`
  
    `netsh winhttp reset proxy`
  
    `ipconfig /flushdns`
  
- Перезапустите компьютер

### Не открывается Telegram в браузере
Запустите **`service.bat`** и выберите **`Update hosts file`**. Если текущий hosts устарел, программа предложит обновить его вручную:  
  - Скопируйте весь текст из запущенного Блокнота
  - В появившейся папке откройте `hosts` через текстовый редактор, запущенный от администратора
  - Вставьте скопированное содержимое в конец `hosts` либо замените ранее добавленный аналогичный блок
  - Сохраните изменения и снова проверьте соединение. Если результата нет, удостоверьтесь, что файл `hosts` действительно был сохранён.

#### Результат не гарантируется. Если способ не сработал, установите [Desktop версию](https://github.com/telegramdesktop/tdesktop/releases) и используйте [локальный прокси](https://github.com/ExistenceAuditor/tg-ws-proxy) либо любой публичный.

### Обход не запускается или больше не работает

> [!IMPORTANT]
> **Любая стратегия со временем может утратить работоспособность.**
> Конкретный вариант способен работать определённый период, а затем перестать из-за обнаружения.
> В этом репозитории собрано много стратегий обхода. Если ни одна не подходит, создайте собственную на базе представленного варианта, изменив его параметры.
> Описание параметров стратегий находится [здесь](https://github.com/bol-van/zapret/blob/master/docs/readme.md#nfqws).

- Проверьте наличие ошибок через `service.bat` -> `Run Diagnostics`

- Удостоверьтесь, что адрес нужного ресурса присутствует в перечне доменов или IP

- Переберите остальные стратегии, в том числе **`ALT`**, **`FAKE`** и другие

- Выполните полную переустановку по инструкции ниже

- Дополнительная информация: [#765](https://github.com/ExistenceAuditor/zapret-discord-youtube/issues/765)

### Как выполнить полное обновление или переустановку?
- Сделайте резервную копию добавленных вами ресурсов и данных
- Перезагрузите устройство
- Выполните `service.bat` -> `Remove Services`
- Откройте `service.bat` -> `Run Diagnostics`, исправьте найденные ошибки и в конце выберите Y
- Удалите каталог с zapret
- Загрузите свежую сборку (`zapret-discord-youtube-...`) [со страницы релизов](https://github.com/ExistenceAuditor/zapret-discord-youtube/releases)
- Щёлкните по архиву правой кнопкой мыши и откройте свойства. Если в правой нижней части есть пункт разблокировки, отметьте его, затем нажмите "Применить" и "ОК"
- Распакуйте архив в новый каталог в корне диска, исключив из пути пробелы и специальные символы
- Поочерёдно запускайте разные скрипты `general` — стратегии. Проверяйте доступность интернет-ресурсов; если они не открываются, завершайте программу через значок замка на панели задач и переходите к следующей стратегии
- Найдя рабочий вариант, добавьте его в автозапуск: `service.bat` -> `Install Service` -> выберите нужную стратегию

### При включённом zapret не запускается игра или приложение

- Убедитесь, что в service.bat для `Game Filter` установлен режим **`disabled`**, а для `IPSet Filter` — **`none`**. Другие значения могут неожиданно повлиять на доступность ресурсов.

### Античит обнаруживает WinDivert

- Следуйте инструкции по адресу: https://github.com/bol-van/zapret-win-bundle/tree/master/windivert-hide

### Windows 7 требует цифровую подпись драйвера WinDivert

- Замените `WinDivert.dll` и `WinDivert64.sys` в каталоге [`bin`](./bin) одноимёнными файлами из [zapret-win-bundle/win7](https://github.com/bol-van/zapret-win-bundle/tree/master/win7)

### После удаления через [**`service.bat`**](./service.bat) служба WinDivert сохраняется

1. Определите имя службы, выполнив команду в командной строке Windows (Win+R, `cmd`):

```cmd
driverquery | find "Divert"
```

2. Завершите работу службы и удалите её следующими командами:

```cmd
sc stop название_из_первого_шага

sc delete название_из_первого_шага
```

### Не открывается <img src="https://cdn-icons-png.flaticon.com/128/1384/1384060.png" height=18 /> YouTube

- Проверьте настройку [Secure DNS](#%EF%B8%8Fиспользование)
- Выключите блокировщик рекламы: известно, что YouTube начал противодействовать таким расширениям.
- Переберите все остальные стратегии, особенно если прежняя недавно перестала работать.
- Дополнительные сведения доступны в [#251](https://github.com/ExistenceAuditor/zapret-discord-youtube/discussions/251)

### Не подключается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968756.png" height=18 /> Discord

- Удостоверьтесь, что [Secure DNS](#%EF%B8%8Fиспользование) настроен
- Сначала желательно определить стратегию, с которой открывается YouTube, и запустить именно её.
- Перейдите в `service.bat` -> `Run Diagnostics` и очистите там кэш Discord.
- Снова откройте приложение Discord и проверьте, помогла ли очистка.
- Перейдите в браузере на https://discord.com/app. Если веб-версия работает, можно пользоваться ею.
- Если Discord недоступен и в браузере, повторно проверьте все стратегии. Иногда один вариант открывает YouTube, но не Discord.
- Другие рекомендации приведены в [#252](https://github.com/ExistenceAuditor/zapret-discord-youtube/discussions/252)

### Не подключается <img src="https://cdn-icons-png.flaticon.com/128/5968/5968804.png" height=18 /> Telegram

- Воспользуйтесь [tg-ws-proxy](https://github.com/ExistenceAuditor/tg-ws-proxy)
- Либо найдите в интернете бесплатный MTProto-прокси

### Не запускаются игры

Игр существует слишком много, поэтому исследовать и исправлять каждую отдельно невозможно.

Наиболее универсальная последовательность действий:
- обновите ipset через `service.bat`, затем активируйте `Game Filter`
- если результата нет, дополнительно включите режим `ipset any`

Учтите: `ipset any` может нарушить доступ ко многим сайтам, поэтому не оставляйте этот режим включённым постоянно. Вместо этого определите все IP-адреса, используемые игрой, и внесите их в `ipset-all.txt`

Если эти действия также не помогли, откройте тему в [Discussions](https://github.com/ExistenceAuditor/zapret-discord-youtube/discussions), а не в issues, и дождитесь рекомендаций других игроков.

## 🗒️Как добавить адреса других ресурсов

Расширяйте перечень адресов для обхода с помощью следующих файлов:
- **`list-general-user.txt`** — домены; их поддомены учитываются автоматически
- **`list-exclude-user.txt`** — исключения доменов, например когда IP сети внесён в `ipset-all.txt`, но отдельный домен из неё фильтровать не нужно
- **`ipset-all.txt`** — IP-адреса и подсети
- **`ipset-exclude-user.txt`** — исключаемые IP-адреса и подсети
  - Файлы вида **`*-user.txt`** создаются автоматически после первого запуска `zapret` или `service.bat`
